# Alta-Profil → Tilda Scanner

Расширение для сбора товаров Alta-Profil и подготовки данных для импорта в Tilda.

## Текущая версия

**14.1.0**

## Как работает сканирование v14.1

1. Расширение сначала находит только **8 уникальных товаров**.
2. Эти 8 карточек реально открываются и парсятся параллельно.
3. Если результат не **8/8**, полный каталог **не запускается**.
4. Только после успешного теста начинается поиск всех товаров во всех трёх группах.
5. После полного поиска товары обрабатываются параллельно — можно выбрать 2, 4, 6 или **8** потоков.
6. Восемь тестовых товаров повторно не открываются.

## Первая установка

1. Нажмите **Code → Download ZIP** в этом репозитории.
2. Распакуйте содержимое в постоянную папку, например `C:\AltaProfilScanner`.
3. Откройте в Яндекс.Браузере `browser://extensions`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку `C:\AltaProfilScanner`.

Эту папку больше не нужно менять.

## Обновление

После того как в GitHub появилась новая версия:

1. Закройте окно расширения, если оно открыто.
2. Дважды щёлкните `UPDATE.bat`.
3. Дождитесь сообщения `Готово`.
4. Откройте `browser://extensions`.
5. Нажмите кнопку **↻ / Обновить** у `Alta-Profil → Tilda Scanner`.

Повторно скачивать ZIP и заново подключать папку не требуется.

## Файлы расширения
