# Alta-Profil → Tilda Scanner

Расширение для сбора товаров Alta-Profil и подготовки данных для импорта в Tilda.

## Текущая версия

**14.2.0**

## Сканирование

1. Сначала расширение находит только **8 уникальных товаров**.
2. Эти 8 карточек реально открываются и парсятся параллельно.
3. Если результат не **8/8**, полный каталог не запускается.
4. После успешного теста начинается поиск всех товаров.
5. Карточки можно обрабатывать в 2, 4, 6 или **8 потоков**.
6. Первые 8 проверенных карточек повторно не открываются.

## Автообновление прямо из расширения

В v14.2 появилась кнопка **«Проверить обновления»**.

Само расширение не имеет права напрямую менять JavaScript-файлы в своей папке, поэтому один раз устанавливается локальный Native Messaging updater. После этого обновление полностью запускается из окна расширения.

### Настройка один раз

1. Сначала обновите локальную папку обычным `UPDATE.bat`, чтобы получить v14.2 и новые файлы.
2. Откройте `browser://extensions` и нажмите **↻ / Обновить** у расширения.
3. В папке расширения один раз запустите `INSTALL_UPDATER.bat`.
4. Установщик попытается сам определить ID расширения. Если не получится, скопируйте ID из окна расширения и вставьте его в установщик.
5. Ещё раз нажмите **↻ / Обновить** в `browser://extensions`.

### Дальше — одна кнопка

Когда в GitHub появляется новая версия:

1. Откройте расширение.
2. Нажмите **«Проверить обновления»**.
3. Если версия новая, updater автоматически скачает `main`, заменит файлы и расширение само перезапустится.
4. Если обновлений нет, расширение просто покажет текущую актуальную версию.

Дополнительных кнопок установки нажимать не нужно.

Вручную скачивать ZIP и запускать `UPDATE.bat` после первоначальной настройки больше не нужно.

## Резервный способ

`UPDATE.bat` остаётся в проекте как запасной способ обновления, если Native Messaging updater не работает.

## Файлы автообновления

- `INSTALL_UPDATER.bat` — одноразовая установка локального updater.
- `native_updater_host.cs` — исходный код локального Native Messaging host.
- `%LOCALAPPDATA%\AltaProfilScannerUpdater\native_updater_host.exe` — собранный локальный updater.
- `%LOCALAPPDATA%\AltaProfilScannerUpdater\native-host.json` — его manifest.

Updater принимает команды только от установленного расширения и скачивает обновление только из `Labbo-star/alta-profil-scanner`.
