# Alta-Profil → Tilda Scanner

Расширение для сбора товаров Alta-Profil и подготовки данных для импорта в Tilda.

## Текущая версия

**14.0.0**

## Первая установка

1. Нажмите **Code → Download ZIP** в этом репозитории.
2. Распакуйте содержимое в постоянную папку, например `C:\AltaProfilScanner`.
3. Откройте в Яндекс.Браузере `browser://extensions`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку `C:\AltaProfilScanner`.

Эту папку больше не нужно менять.

## Обновление

После того как в GitHub появилась новая версия:

1. Закройте окно расширения, если оно открыто.
2. Дважды щёлкните `UPDATE.bat`.
3. Дождитесь сообщения `Готово`.
4. Откройте `browser://extensions`.
5. Нажмите кнопку обновления `↻` у `Alta-Profil → Tilda Scanner`.

Повторно скачивать ZIP, удалять старое расширение и заново выбирать папку не требуется.

## Что делает UPDATE.bat

Updater скачивает последнюю версию ветки `main` напрямую с GitHub и заменяет рабочие файлы расширения:

- `manifest.json`
- `background.js`
- `product.js`
- `popup.js`
- `popup.html`
- `README.md`

Сам `UPDATE.bat` не перезаписывается, поэтому updater остаётся стабильным.
