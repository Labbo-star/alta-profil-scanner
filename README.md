# Alta-Profil → Tilda Scanner

Расширение для сбора товаров Alta-Profil и подготовки данных для импорта в Tilda.

## Текущая версия

**14.2.1**

## Сканирование

1. Сначала расширение находит только **8 уникальных товаров**.
2. Эти 8 карточек реально открываются и парсятся параллельно.
3. Если результат не **8/8**, полный каталог не запускается.
4. После успешного теста начинается поиск всех товаров.
5. Карточки можно обрабатывать в 2, 4, 6 или **8 потоков**.
6. Первые 8 проверенных карточек повторно не открываются.

## Автообновление внутри расширения

Кнопка **«Проверить обновления»** работает через локальный Native Messaging updater. Само расширение не может напрямую переписывать собственные JS-файлы, поэтому локальный updater устанавливается один раз.

### Исправление v14.2.1

Установщик updater стал надёжнее:

- проверяет полный 32-символьный ID расширения;
- показывает найденный ID и просит подтвердить его;
- регистрирует native host для Yandex Browser, Chrome и Chromium;
- создаёт записи для 32- и 64-битных представлений реестра;
- проверяет наличие EXE, manifest и записи реестра;
- добавлен `CHECK_UPDATER.bat` для диагностики.

### Настройка один раз

1. Запустите обычный `UPDATE.bat`, чтобы получить последнюю версию файлов.
2. В `browser://extensions` нажмите **↻ / Обновить** у Alta-Profil Scanner.
3. Запустите `INSTALL_UPDATER.bat`.
4. Если установщик показывает найденный ID расширения — сравните его с ID в окне расширения и подтвердите только если они совпадают.
5. Если ID не найден, вставьте полный ID вручную.
6. Дождитесь сообщения **«УСТАНОВКА УСПЕШНА»**.
7. **Полностью закройте все окна Яндекс.Браузера и откройте браузер заново.**
8. Откройте расширение и нажмите **«Проверить обновления»**.

### Если не работает

Запустите `CHECK_UPDATER.bat`. Он создаст на рабочем столе файл `alta-updater-diagnostic.txt` с проверкой:

- native updater EXE;
- native-host manifest;
- ID расширения;
- записей NativeMessagingHosts в реестре.

Пришлите этот файл для диагностики.

## Дальше — одна кнопка

Когда в GitHub появляется новая версия:

1. Откройте расширение.
2. Нажмите **«Проверить обновления»**.
3. Если версия новая, updater скачает `main`, заменит файлы и расширение перезапустится.
4. Если обновлений нет, будет показана текущая актуальная версия.

`UPDATE.bat` остаётся резервным способом обновления.
